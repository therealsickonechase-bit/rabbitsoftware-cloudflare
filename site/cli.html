RabbitSoftware CLI

Local record lookup, public corpus access, and optional signed account reads. No uploads or hosted AI.

Download CLI ZIP · ZIP SHA-256 checksum

This new reconstruction bundles synthetic demo records, not your real chain. It is not the original RabbitSoftware application, an installer, or an automatic connection to Cloudflare records.

Run in your terminal

  1. Install Python 3.10 or newer if needed. Local/public modes need no extra packages; signed account reads require the optional cryptography dependency.
  2. Download the ZIP, check its SHA-256, and extract the whole folder.
  3. Open a terminal in the extracted folder containing rabbit.py, then run:
python rabbit.py --demo chat
python rabbit.py --demo ask "what's on the chain"
python rabbit.py --demo ask "find BRCA1 on the chain"

Windows can use py -3; macOS/Linux can use python3 instead of python. Tested on Windows with Python 3.12.10; other platforms have not been tested. No global rabbit command is installed.

Interactive chat recognizes list, find/search, and show-entry questions. Type exit to quit. This is deterministic lookup, not free-form AI.

Check the download

On Windows, compare the output below with the linked ZIP checksum:

Get-FileHash .\rabbitsoftware-cli-0.2.1.zip -Algorithm SHA256

The ZIP includes a per-file checksum manifest, README, and license notice. Checksums detect changed bytes; they are not independent signatures. Review the code before running it. Never pipe a download straight into your shell.

Use your own local records

python rabbit.py --chain "C:\path\to\records.json" ask "find BRCA1 on the chain"

The bundled README documents rabbitsoftware.local-public-lookup.v1, existing public research/Maxwell v1 snapshots, and account DNA JSON. Private DNA entries stay local. Ordering and previous-hash linkage are checked where applicable; block hashes, event signatures, and consensus are not independently verified. Do not relabel private records.

Use the original commands with a selected source

python rabbit.py --chain "C:\path\to\existing-chain.json" --remember ask "show entry 2"
python rabbit.py ask "what's on the chain"
python rabbit.py ask "show entry 2"

Replace the path with an actual existing file. --remember saves only paths and source selection to ~/.rabbitsoftware/connection.json, not key values or records. Delete that file to forget. Entry 2 means the second item, not a block/event identifier.

Public research and private accounts remain separate

python rabbit.py --public-corpus ask "what's on the chain"
python -m pip install -r requirements-account.txt
python rabbit.py --credentials "C:\private\device.json" --dna "your-chain-name" ask "show entry 2"

The public corpus is an existing research collection, not a blockchain or your account chain. See the website corpus and local-file viewer. Account reads require each user's existing registered Ed25519 device credential file, as documented in README. Never enter that file into the website or chat. No account registration or authentication bypass; real device access still needs live verification with your credentials.

The previously published offline-only CLI 0.1.0 remains unchanged.
