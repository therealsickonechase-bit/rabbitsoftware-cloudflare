Local browser agent / version 0.2.1

Run an agent locally.

Offline record lookup, Europe PMC papers, and optional Tavily web search. No hosted AI or record uploads.

Download local agent ZIP · SHA-256 checksum

Start the local interface

Install Python 3.10+, verify the checksum, extract the whole ZIP, and open a terminal in the folder containing run_agent.py. No extra packages are required.

python run_agent.py --host 127.0.0.1 --port 8765

Open http://127.0.0.1:8765/ in your browser. The command uses your remembered source or labeled demo records if none is configured. Stop with Ctrl+C. Only loopback binding is allowed. Use a different port if occupied.

Windows can use py -3, macOS/Linux python3. Tested on Windows/Python 3.12; other platforms are not tested. This is a new reconstruction, not the original application.

Choose a mode

  • Source lookup: list, find, or show demo/local/archive entries. Use --chain "C:\path\to\records.json" for an existing local file; CLI instructions document supported research, Maxwell, and DNA formats and signed account reads. Real sources are never discovered automatically.
  • Europe PMC papers: search public literature with fresh consent. No API key needed.
  • Tavily web search: optional, using each visitor's own key. Restart with the command below and enter the key in the hidden terminal prompt.
python run_agent.py --host 127.0.0.1 --port 8765 --tavily

Never paste a key into chat, a URL, or a command argument. The key is kept in memory and is not saved or exposed to the browser. Your Tavily allowance and billing apply; keep paid overages disabled if desired.

Data boundaries

Each approved search sends only the public query to the selected provider. Local/account records stay separate. Results are public-source links and snippets, not chain records or verified AI answers. No autonomous loops, full-page fetching, account registration, or model calls.

Research viewer and remembered source

python research_viewer.py --chain "C:\path\to\existing-chain.json" --remember
python research_viewer.py
python rabbit.py ask "what's on the chain"
python rabbit.py ask "show entry 2"

The viewer starts the same loopback interface. Remembered settings contain paths/selection, not records or keys. Use --public-corpus for public research batches, which are not a blockchain. Signed account reads use your own existing device credential file and optional cryptography dependency; see the included CLI README. No inspected owner data is bundled or published. The website viewer keeps public corpus and browser-only local files separate.

Five provider attempts per rolling hour per process, including failures; restarting resets this local limit. No silent retries. Do not enter personal, genomic, biosignal, health data, or credentials. Pattern checks are incomplete. Not medical advice.

Do not run on an untrusted shared computer. Host, origin, and session-token checks protect form requests but do not stop privileged local processes. Browser history and terminal scrollback may remain.

Verify and inspect

Get-FileHash .\rabbitsoftware-agent-0.2.1.zip -Algorithm SHA256

Compare with the linked checksum. README, code, license notice, demo records, and per-file hashes are included. Checksums are not independent signatures. Inspect code before running; no private records, keys, dependencies, or model weights are bundled.
