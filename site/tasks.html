    How it works and limits

    Flow: this page sends your task to the rabbitsoftware-tasks Worker, which stores it in a queue and runs tasks one at a time with Cloudflare Workers AI (Qwen). The page checks back every few seconds. The task ID is only kept in this browser; anyone with the ID can read the result.

    Limits: 5 tasks per network per hour, 100 tasks per UTC day for everyone, at most 25 waiting at once, 8,000 characters per task. Accepted tasks count even if they fail. There are no automatic retries.

    Storage: your text is deleted as soon as the task finishes; the result is kept for 7 days. Your network address is stored only as a one-way hash for the hourly limit.

    Pattern checks refuse obvious email addresses, phone numbers and credentials, but cannot catch everything. Do not submit personal, health or private information. AI answers can be wrong. Read website privacy.
