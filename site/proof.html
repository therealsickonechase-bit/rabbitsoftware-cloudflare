      Check it yourself

      1. Download an anchor’s anchor.json and anchor.json.ots from the list above. The anchor is a small file holding the newest head hashes of the RabbitOS ledger and the Maxwell chain.
      2. Run verify-anchor.py (Python, standard library only): python verify-anchor.py <anchor id>. It replays the proof and compares it with the Merkle root of the Bitcoin block it names, fetched from a public Bitcoin API.
      3. Or use the standard ots verify anchor.json.ots tool from OpenTimestamps with your own Bitcoin node.
      4. The .tsr file is a second witness: a standard signed timestamp from the free FreeTSA authority. Verify it with openssl ts -verify and the certificates published at freetsa.org.

      A timestamp proves a fingerprint existed by that time. It does not prove the underlying record is true, and a research record listed here is a pointer to a public source, not an endorsement. See the network map, how the chain works and the live status.
