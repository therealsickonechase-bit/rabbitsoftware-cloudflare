Public research corpus

The API exposes public research records, not blocks or an account chain. The site build publishes assets/public-corpus.json, a same-origin metadata-only snapshot regenerated from public batch endpoints. It includes source, external identifier, title, source URL, and publication date only—not abstracts or account archives.

For live, searchable, downloadable public research data and the chain ledger head, use the research data hub.

Snapshot searches run locally in this tab. Query text is not sent to the API or any other service; only the static asset request reaches this website's host. The data may be out of date until the snapshot is rebuilt and published. The checked API endpoints do not return CORS permission, so this viewer deliberately does not make browser API searches.

    Open one local JSON file

    Choose a file yourself. This website viewer reads it in this tab only: there is no upload, account login, AI, network request for file contents, or automatic file discovery. Its only network data is the same-origin public metadata snapshot. Files are limited to 1 MiB and 1,000 entries. Supported formats are rabbitsoftware.local-public-lookup.v1, explicitly public v1 events/chain archives, and account-scoped DNA JSON with name, account and entries. The viewer does not verify hashes, ordering, signatures, or consensus.

    Privacy: account-scoped DNA files may contain private data and are labeled private here. The account identifier is never displayed or sent. “Public” labels inside other files are declarations, not proof that their contents are safe to share. Use files you trust and are authorized to inspect.
